Work

ThermoScope

The problem
A satellite can tell you something is burning at a spot in Gujarat. It can't tell you what caused it.
What I built
It groups raw NASA FIRMS detections into 20,409 events, adds OpenStreetMap, power-plant and land-cover context, and a LightGBM model labels each as industrial, gas flare, crop residue or wildfire. A map dashboard sits on top, with 496 tests behind it. It's near real time: inference reruns every 30 minutes on the latest live FIRMS data.
  • Python
  • LightGBM
  • NASA FIRMS
  • OpenStreetMap
  • Leaflet
  • Live demo for ThermoScope
  • GitHub for ThermoScope

Built with Suvarcha Wadhwa. Mentor: Chiranjit Dutta.

Retention Decision Engine

The problem
A subscription business can see who already left. It can't tell who's about to, or why.
What I built
Calibrated LightGBM and survival models predict who will lapse at 7 and 30 days, with per-customer reason codes. Served through FastAPI and Valkey with an MLflow registry, a Streamlit dashboard and about 2,900 tests, all in Docker Compose.
  • Python
  • LightGBM
  • SHAP
  • FastAPI
  • Valkey
  • MLflow
  • Docker
  • Streamlit
  • GitHub for Retention Decision Engine

Legal RAG Chatbot

The problem
A language model can tell you what the law says. It can't show you where it read it.
What I built
It answers from indexed Indian statutes and judgments with bracketed citations, then checks that every citation matches a passage it retrieved, retrying or flagging it if not. Built in a week.
  • Python
  • FastAPI
  • LangChain
  • ChromaDB
  • sentence-transformers

How I work

  1. 01

    Pass marks first

    I decide what counts as good enough before I see a single result.

  2. 02

    Misses stay visible

    If a target isn't hit, the report says "not met". I don't tune it until it looks fine.

  3. 03

    Context stays out

    Data that gives the answer away never goes into the model's inputs.
